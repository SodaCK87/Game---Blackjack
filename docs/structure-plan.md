## 搬移計畫

本輪沒有紅燈，以下只列不排。每一筆都能單獨執行、單獨回復。

### 規範修訂批（S-01 到 S-07）

只改 `docs\檔案結構規範.md` 與 `.gitignore:5` 的註解，不動任何程式檔，一個 commit。

1. 做法：用 Edit 改文字（含中文，不可用 `Get-Content`／`Set-Content` 轉手）；`.gitignore` 只改註解，不改 `dist/` 那行（除非選了「刪掉 `dist`」）。
2. 搬完怎麼驗：
   1. `(Get-Content "docs\檔案結構規範.md" -Encoding UTF8).Count` 不超過 150。
   2. 交付把關 E0、E4、E10 照舊 PASS：`& "C:\Users\ben12\Downloads\ClaudeOnly\Claude規則研究\探針\交付把關\Probe-Delivery.ps1" -Project "<專案路徑>"`。
   3. `git check-ignore -v --no-index dist/a.html tools/_shots/x.png` 照舊命中，`app/index.html` 照舊不命中。
   4. `docs\問題台帳.md:6` 用標題文字〈缺陷編號、嚴重度與狀態〉指過來，改到那個標題就要一起改；動到標題時照 `github-docs-verify` 的消費端驗法驗錨點。
3. 驗不過怎麼退：`git revert <該 commit>`；還沒 commit 就 `git restore -- docs/檔案結構規範.md .gitignore`。

### 第 1 批：零引用的暫存／實驗檔 → 封存

無已追蹤的檔。`tools\_shots\` 是被擋住的暫存，清不清等 S-05 寫進規範後照規則做；刪除由使用者自己執行。

### 第 2 批：可重建的產出物 → 移出版控

無。`app\lib\three.js` 照規範第 30 行刻意進版控（Pages 與雙擊不經建置），不移出。

### 第 3 批：有引用、引用全在專案內 → 搬移 ＋ 改引用

只在 S-01 選「搬」而不是「改規範」時才有，不建議：

1. 做法：`git mv tools/check_live.js tests/live_check.js`（不能叫 `check_*.js`，否則被 `npm test` 收進去），同一個 commit 改 `CLAUDE.md:15`、`目標路線圖.md:17`、`app\index.html:7` 的路徑；`docs\版本紀錄.md` 是歷史敘事不改；規範〈命名〉驗證腳本那列加 `live_check.js` 例外。
2. 搬完怎麼驗：`node tests/live_check.js` 四組全過；`npm test` 的測試數仍是 107（沒有把它收進去）；E7 與組 C 的路徑存在檢查（`%TEMP%\盤點C-work\refcheck.js`）0 筆 MISSING。
3. 退回：`git revert <該 commit>`。
