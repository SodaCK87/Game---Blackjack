## v0.21.1（2026-11-16）修 BJK-11：矮的直式手機上，對白泡泡被按鈕與版本號擋住

使用者在 Android Chrome 直拿時回報：荷官的對白泡泡被左上角的音效、戰績鈕與右上角的版本號擋住、疊在一起，要「預設側邊收闔，點擊再彈出來」。

1. 原因：真手機的網址列吃掉一截，畫布加操作列約 720 CSS 像素高，探針一直只量 390×844。直式時荷官放大 2.2 倍、框景貼齊畫布底，畫面一矮頭頂就貼近畫面頂：390×720 頭框頂端在 61 px，兩行的泡泡（70 px）放不上去，被夾回 top 8，同時壓到按鈕、版本號和頭頂。
2. 直式畫面（跟 `main.js` 排版的判斷一樣：畫布寬／高 < 1）把音效、戰績、版本號收進左邊緣的拉頁，只露一個 34×56 的把手；點把手滑出，再點把手、點拉頁外面或按 Esc 收回。把手的高度由 `main.js` 排版時算，放在牆上緣與荷官那條直邊桌緣的中間（390×844 在 325–381、390×720 在 219–275、360×640 在 184–240），那一帶左邊緣是空的牆，不碰泡泡、名牌與牌桌。橫式畫面的版面不變。
3. 滑出用 CSS transition（transform 0.2 秒），不開 JS 動畫、不重畫牌桌。開頁與轉方向那一下先關掉 transition 再套位置（`#drawer.still`），不然開頁就會看到拉頁從畫面裡滑走。
4. `dealer.js` 的 `placeBubble` 多一條路：右邊放不下、頭頂也放不下時，放到臉旁邊比較寬的那一側，寬度縮到那一側放得下，字多就多排幾行（390×720 待機講長句：左側 154 寬、4 行，底端 133，把手從 219 起；360×640 最高到 148，把手從 184 起）。原本量泡泡寬度時它還停在上一次的位置，靠右時被瀏覽器擠窄、量到的寬度是錯的；改成先擺到左上角再量。
5. 測試：
   1. `check_dealer.js`：長句泡泡與「五種表情」兩組各加 390×720、360×640，五種表情多講一句短句，多一條判準「不跟看得到的按鈕、把手、版本號疊」；陽性對照兩個：頭頂放不下照舊夾回頂端 → 判蓋到臉，直式不收拉頁 → 判疊到按鈕。
   2. 新檔 `check_drawer.js`（5 條與 7 個陽性對照），全部用 CDP 真的點：直式三種尺寸開頁那一刻就是收起的、只露把手、把手 ≥ 44 高且在牆與桌緣之間、不壓名牌；拉開後音效與戰績點得到（44 見方）、版本號看得到；點音效拉頁不收，點外面、再點把手會收；全程重畫 0 次、`requestAnimationFrame` 0 次。橫式（桌機、橫拿的手機）沒有把手，按鈕與版本號的位置跟原本一樣。對照：預設展開、把手放到桌緣、開頁照播滑動、拉開時仍藏著、拿掉點外面收回、拉開時用 JS 重畫、橫式也收進拉頁，各自判紅。
   3. `check_ui_text.js` 讀版本號、`check_ui_stats.js` 按戰績鈕，直式時先拉開把手；版本號那條多量 390×720。`tools\check_live.js` 讀的是 `data-bjk` 裡的版號，不受影響。`tools\shoot.js` 預設多截 390×720 收起與拉開兩張。
   4. 踩到的坑：探針點完把手先固定等 350 毫秒再讀位置，十支測試檔平行跑、機器忙時拉頁還沒滑完（量到版本號 left −3.5，判成跑出畫面）。改成等 `#drawer` 的 `getAnimations()` 全部 `finished`（`ui_util.js` 的 `DRAWER_SETTLED`）。
6. ⚠️ 只在這台的 Edge 用模擬尺寸驗過，沒在真手機上點過把手。只改了 view、測試與 `version.js` 的版號，沒跑 `mutants`。
7. 版本紀錄超過 12 個版本，v0.13.1 原樣搬到 `docs\版本紀錄_歷史.md`。

## v0.19.0（2026-11-07）牌與籌碼的立體感：軟影子貼片、紙緣與倒角亮暗

使用者要牌與籌碼更立體。現況是牌與籌碼本來就投即時陰影，但燈幾乎在正上方、牌貼平在絨布上，影子全被自己蓋住，整手牌疊起來看不出上下層。從「貼圖亮暗＋軟影子貼片」「只改貼圖」「加強即時陰影」三案選了第一案。

1. 軟影子貼片：每張牌底下、每疊籌碼最底那片底下墊一片開頁畫一次的模糊影子（`textures.js` 的 `cardShadow`、`chipShadow`）。牌的貼片貼在牌底下，疊牌時上一張的影子落在下一張上。透明＋貼圖跟棄牌盒的玻璃同一支著色器，不多編譯；不收即時陰影、陰影貼圖不變。
2. 蓋著的牌（荷官底牌）沒有影子：貼片法線朝牌的上方，牌翻過來時背面朝鏡頭被剔除，不會浮到牌背上面。籌碼的貼片掛在最底那片上、不掛在整疊上，`director.js` 拿整疊的子物件數當片數算高度。
3. 貼圖亮暗：牌面與牌背四邊往外漸暗、內側一道亮線（紙的厚度，四邊都畫，因為每個座位的牌轉的角度不同）；籌碼頂面外緣改成先亮一圈再壓暗收邊的倒角，側面上半迎光、下半背光。
